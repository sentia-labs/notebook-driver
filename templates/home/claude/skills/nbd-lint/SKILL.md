# Vault health check

Arguments: `$ARGUMENTS` — the report `nbd lint --agent` wrote (`.nbd/context/lint.md`).

1. **Mechanics** (from the report), fixing what is safe without asking:
   - broken `[[links]]`: point them at the right slug, or unlink if no note should exist;
   - footnote quotes not found on their page: re-read the page and correct the quote; if the page
     no longer supports the claim, mark it `> [!outdated]` or remove it;
   - missing `type`, `description` or `sources`: fill them from the note and its pages;
   - duplicate file names: ask which to merge or rename.
2. **Judgement** (AGENTS.md §5 Lint): contradictions between notes; stale claims without
   `[!outdated]`; people or topics mentioned on 3+ pages without their own note; projects with no
   next step or untouched for 4+ weeks; notes that should link but don't.
3. Ask the human (AskUserQuestion) before anything that changes meaning: merging notes,
   archiving projects, resolving a contradiction.
4. Append `## [YYYY-MM-DD HH:MM] lint | N issues, M fixed` to `vault/log.md` and summarise in two
   or three lines.

Never touch the notebook. `index.md` is regenerated by `nbd`; don't edit it.
